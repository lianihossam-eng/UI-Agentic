# Code of Conduct

## Our commitment

We want UI-Agentic to be a professional, technically rigorous, and welcoming open-source project.

Participants are expected to interact with respect, assume good faith, and separate technical disagreement from personal criticism.

## Expected behavior

Examples of constructive behavior include:

- giving specific, evidence-based technical feedback;
- acknowledging uncertainty when evidence is incomplete;
- challenging claims without attacking contributors;
- explaining trade-offs and alternative approaches;
- respecting different levels of experience;
- keeping discussions focused on the project and its users;
- correcting mistakes transparently when new evidence changes the conclusion.

## Unacceptable behavior

The following is not acceptable:

- harassment, threats, intimidation, or discriminatory conduct;
- personal insults or targeted hostility;
- publishing private information without permission;
- deliberately misleading technical claims;
- manipulating verification results to create unsupported confidence;
- repeatedly disrupting discussions after maintainers have requested a return to scope;
- any conduct that would reasonably make participation unsafe or hostile.

## Technical integrity

Because this project is about evidence and verification, technical integrity is part of the community standard.

Contributors should not knowingly:

- convert missing evidence into `PASS`;
- present sampling as stronger proof without a valid method;
- hide hard failures behind aggregate scores;
- misattribute a human or agent review;
- reuse stale evidence while claiming current provenance;
- weaken a gate solely to make a result appear successful.

Mistakes are expected in research and engineering. Concealing them is not.

## Enforcement

Project maintainers may edit, remove, or reject comments, issues, pull requests, or contributions that violate this Code of Conduct. Repeated or serious violations may result in temporary or permanent exclusion from project spaces.

When possible, moderation decisions should be proportional, documented, and focused on restoring productive participation.

## Reporting

If you experience or observe a Code of Conduct problem, contact the project maintainer privately using the contact method listed in `SECURITY.md` or the repository owner's public contact information.

Do not publish sensitive personal information as part of a public report.

## Scope

This Code of Conduct applies to project-managed spaces, including issues, pull requests, discussions, reviews, and other collaboration channels used for UI-Agentic.
